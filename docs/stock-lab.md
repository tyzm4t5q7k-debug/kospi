# 국내 주식 분석 메뉴

`/stocks`는 기존 포트폴리오에 추가한 독립 화면입니다. 홈의 국내 주식 분석 링크로 이동합니다.

## 데이터

- 토스증권 공식 REST API: 현재가, 수정주가 OHLCV 일봉·1분봉, 투자자별 순매수 수량, 외국인 보유량/지분율, 공매도, 신용융자 잔고, 대차잔고.
- 서버의 `.env.local` 또는 배포 환경변수에 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET` 설정. 키는 클라이언트 번들이나 Git에 포함하지 않습니다. 조회 API만 호출하며 계좌 헤더와 주문 API는 사용하지 않습니다.
- 공식 API는 호출 서버의 허용 IP 등록이 필요합니다. Vercel에서 연결할 때는 실제 송신 IP 조건을 먼저 확인하고 필요한 경우 고정 송신 IP를 가진 서버를 사용합니다.
- 현재가는 15초 폴링, 차트 60초, 수급 캐시 5분. 화면이 숨겨지면 폴링을 중단합니다. 체결 틱 WebSocket 스트리밍은 아직 구현하지 않았습니다.
- 토스 연결 실패 시 Yahoo OHLCV로 전환하며 화면에 출처와 실패 안내를 표시합니다. Yahoo에는 지연 가능성이 있고 수정주가 기준이 토스와 다를 수 있습니다. 수급은 대체·추정하지 않습니다.
- 토스 인증 토큰은 프로세스 내에서 재사용하고 발급 중복을 합칩니다. 토스는 새 토큰 발급 시 이전 토큰을 무효화합니다. 따라서 여러 서버 인스턴스로 운영하려면 공유 토큰 저장소/단일 토큰 발급기를 추가하거나 외부에서 갱신하는 `TOSS_ACCESS_TOKEN`을 모든 인스턴스에 동일하게 공급해야 합니다. 현재 구현은 단일 프로세스에서 검증하는 구성입니다. 이 상태로 무제한 서버리스 확장을 활성화하지 않습니다.
- API의 일별 순매수와 외국인 보유는 잠정/확정 시각이 다르고 신용은 T+1 반영입니다. 비어 있는 자료는 null로 유지합니다. 기관·개인 보유수량은 미제공입니다.

## 지표

가격 상단 12종과 가격·거래량 기반 하단 25종을 선택할 수 있습니다. 파라미터·산식은 `lib/stock-indicators.ts`의 지표 카탈로그 및 화면에 표시됩니다. 매물대는 봉 고저 범위에 거래량을 균등 배분한 근사치입니다. 일목 선행/후행선은 시각적 이동을 적용하며 미래 영역 확장은 미구현입니다. 프랙탈은 우측 2봉이 생긴 뒤에만 확정합니다. VWAP는 1분봉에서 한국시간 거래일별로 초기화하고 장 중간부터 시작하는 첫 날짜는 생략합니다. 모든 가격 기준은 제공 API의 거래소/수정주가 정책을 따르며 증권사 차트와 초기화 방식 차이로 다를 수 있습니다.

## 매수 검토 후보

명시된 30종목만 분석합니다. 전종목 순위가 아닙니다. 일봉 스윙용 규칙이며 완료된 일봉 최소 90개가 필요합니다. 당일 봉은 장 종료 여부와 무관하게 보수적으로 제외합니다. 가장 최근 일봉이 7일 넘게 지난 경우 판정을 보류합니다.

서로 다른 세 전략을 각각 4개의 기술조건으로 판정합니다. 화면의 0~4는 가장 많이 충족한 전략의 조건 수이며 수익 확률이나 전략 간 우열을 의미하지 않습니다. 내부 score는 정렬 호환을 위한 조건 수×25입니다.

- 추세 지속: 종가>MA20>MA60 및 MA20 상승 / ADX14≥20와 +DI>-DI / MACD 히스토그램 양수·증가 및 RSI14 40~70 / 이전 20일 평균 이상의 거래량과 5봉 전보다 높은 OBV.
- 변동성 수축 후 돌파: 종가가 이전 20봉 고가 돌파 / 전일 볼린저 밴드폭이 그 이전 60봉 분포의 하위 30% / 종가>MA60 및 +DI>-DI / 거래량 평균 1.5배 이상과 MFI14 50~80. 돌파 기준 고가와 수축 판정에 현재 봉은 사용하지 않습니다.
- 상승 추세 눌림목: MA20>MA60 및 종가>MA60 / 이전 5봉 중 MA60 위에서 MA20의 102% 이하로 접근한 뒤 현재 MA20 위 양봉 / RSI14 40~65 상승 및 스토캐스틱 K가 전일 50 이하에서 D를 상향 교차 / 거래량 평균의 0.8배 이상 및 OBV 상승.

하나의 전략에서 4조건 모두 충족하고, 최근 완료된 5거래일의 외국인·기관 순매수 합계가 각각 양수이며 위험 필터를 통과할 때만 매수 검토입니다. 필요한 5일 중 하루라도 수급이 누락되면 판정을 보류합니다. 수급은 모든 지표에 가산점을 중복 부여하는 대신 별도 확인 조건으로 사용합니다.

ATR14/종가>5%, RSI14>75, MA20에서 2ATR 초과 이격, 거래량 0, 이전 20일 평균 추정 거래대금(종가×거래량)<10억원은 후보에서 제외합니다. 외국인·기관 동반 순매도도 제외 조건입니다. 공매도/거래량, 신용·대차잔고 변화는 별도 기준일을 붙인 참고 정보이며 증가를 자동으로 하락 신호로 보지 않습니다. 잔고는 최근 5거래일 중 신용·대차가 함께 있는 첫날과 마지막날을 비교하며 2개 미만이면 미제공 처리합니다.

모든 문턱값은 검증할 설계 가정입니다. 백테스트·수익성 검증, 수수료/슬리피지, 시장지수·기업 실적/뉴스 반영은 아직 없습니다. 지표 간 상관이 있으므로 조건 수를 독립적인 확률 증거로 해석하지 않습니다.

## 검증

`npm test`, `npx tsc --noEmit`, `npm run build`. 새 테스트는 알려진 Wilder RSI 값, 평균 시드, 영분모/0거래량, VWAP 초기화, 프랙탈 확정, 미완료 봉의 점수 제외, 거래량 보존, 누락 수급과 단위 변환을 확인합니다.
