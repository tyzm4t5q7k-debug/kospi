# 프로젝트 설명 준비

아래 내용은 제출자가 검토하고 자신의 말로 설명하기 위한 준비 자료입니다. 실제 경험으로 확인하지 않은 기여나 분석 수행을 추가하지 않습니다.

## 설명 순서

1. 경제·금융 뉴스를 정리하며 국내외 시장 움직임을 숫자로 비교할 필요를 느꼈다는 문제의식.
2. 지수의 동행 정도, 해외투자의 환율 효과, 기업의 현금흐름으로 질문을 구분한 구성.
3. 대표 사례 하나를 골라 질문 → 표본과 산식 → 관측 결과 → 한계 순서로 설명.
4. 프로젝트 방향은 본인이 선택했고 자료 정리·구현·초안에 Codex를 활용했다는 기여 구분.
5. 추가 검증에 필요한 실제 상품·일별 시계열·기업 계약 자료를 구체적으로 제시.

## 반드시 이해할 질문

| 질문 | 설명의 핵심 |
| --- | --- |
| 왜 가격지수 수준으로 상관관계를 계산하지 않았나요? | 지수 수준의 추세와 수익률의 동행은 다릅니다. 비교한 대상은 전년 대비 변동률입니다. |
| 연간 상관계수가 높으면 내일도 같이 움직이나요? | 연간 표본 10개는 일별 움직임이나 미래를 예측하지 못합니다. |
| 같은 날짜의 종가면 동시 비교인가요? | 한국·미국 장 마감과 환율 관측 시각이 다릅니다. 정보가 알려진 시점을 맞추려면 별도의 시차 정렬이 필요합니다. |
| 환율 효과를 단순히 더하면 되나요? | 가격과 환율 변화의 곱인 교차효과가 있습니다. 가격 +10%, 환율 -10%면 원화 결과는 -1%입니다. |
| 2024년 환율이 유리했으니 환헤지를 하지 않는 편이 좋나요? | 특정 연도의 결과로 결정할 수 없습니다. 같은 해 3분기는 환율이 원화 성과를 낮췄습니다. |
| 수출 기업에는 환율 상승이 무조건 유리한가요? | 외화 지급, 차입의 금리 조건, 결제 일정과 기존 환헤지까지 확인해야 합니다. |
| 이 자료의 가장 큰 약점은 무엇인가요? | 연간 표본의 크기와 2차 자료, 월별 관측의 제한, 가상 기업의 단순화입니다. |
| 직접 한 부분과 AI가 한 부분은 무엇인가요? | 프로젝트 주제·활용 목적·지원 범위는 본인이 정했고, 자료 정리·개발·초안·자동 검증에는 Codex를 활용했습니다. 직접 검토·수정한 부분만 추가해서 설명합니다. |

## 지원 직무에 맞춰 먼저 보여줄 사례

- 기업금융: 사례 03의 순수취·순지급 및 금리 재산정 질문.
- 개인금융·자산관리: 사례 02의 원화 성과 설명과 지출 통화·기간 확인.
- 증권 리서치: 사례 01의 표본 민감도와 인과 추정의 한계.
- 자산운용: 사례 02의 가격·환율 기여 분해와 사례 01의 분산 효과 검토.
