# 대표 분석의 계산·검증 기준

자료 확인일: 2026-09-11. 대표 분석은 2015~2024년의 연간 표본과 2024년의 월별 표본을 고정해 재현성을 확보한 사례 연구입니다. 최신 시장 상황을 설명하는 자료는 아닙니다. 이후 연도로 표본을 확장하는 작업은 별도 검증으로 구분합니다.

## 출처와 표본

| 사례 | 자료 | 표본과 기준 | 자료의 제한 |
| --- | --- | --- | --- |
| 01 시장 동조화 | Wikipedia KOSPI·NASDAQ Composite 연간 성과표 | 2014~2024년 각 시장의 최종 종가 11개 → 2015~2024년 연간 수익률 10개 | 2차 편집 자료. KRX 원자료와 전수 대조하지 않음. 각 시장 연말 거래일이 다를 수 있음 |
| 02 환율 효과 | FRED NASDAQCOM·DEXKOUS | 2023-12-29~2024-12-31, 두 자료가 함께 존재하는 월별 마지막 관측일 13개 | 미국 주식 종가와 뉴욕 정오 환율의 관측 시각이 다름 |
| 03 기업 현금흐름 | 공개한 가상 입력값 | 차입금 10억원, 변동금리 60%, 12개월, 순수취 10만 달러 | 실제 기업·대출심사·전망 자료가 아님 |

원자료 URL은 `lib/case-data.ts`와 사이트 각 사례에 기재합니다. 사례 01의 NASDAQ 2023·2024년 말은 FRED와 대조했습니다. 직접 계산한 결과와 외부 출처가 설명한 일반 개념을 구분합니다.

## 계산

- 수익률: `(종료 지수 / 시작 지수 - 1) × 100`. 반올림한 외부 수익률을 다시 사용하지 않습니다.
- 상관계수: 가격 수준이 아닌 10개 연간 수익률 쌍의 Pearson 상관계수. 5년씩 분할 및 한 해씩 제외한 결과는 표본 민감도입니다. 유의성·구조 변화·인과관계의 검정이 아닙니다.
- 원화 수익률: `(종료 NASDAQ × 종료 원/달러) / (시작 NASDAQ × 시작 원/달러) - 1`. 달러 수익률·환율 변화율·두 값의 교차효과로 분해합니다.
- 분기 수익률: 직전 분기 말부터 해당 분기 말까지 계산. 연간 수익률은 분기 수익률을 더하지 않고 복리로 연결합니다.
- 외화결제 효과: `(달러 수취 - 달러 지급) × (변경 환율 - 기준 환율)`.
- 추가 이자: `차입금 × 변동금리 비중 × 금리 변화(%p / 100) × 개월 수 / 12`.
- 순효과: `외화결제 효과 - 추가 이자`. 회계상 순이익·기업가치 변화가 아닙니다.

배당·비용·세금·환헤지 효과는 제외합니다. 연간·월별 표본으로 일별 최대 낙폭을 계산하지 않습니다. 모든 표는 표시 단계에서만 반올림합니다.

## 재현

```sh
npm ci
npm test
node scripts/export-case-study.cjs
python scripts/build-submission-pdf.py
npm run build
```

PDF 제작에는 Python reportlab이 필요합니다. 웹사이트의 계산 모델과 동일한 JSON을 사용하며 한국어 글꼴은 저장소의 OFL 글꼴을 사용합니다. 결과 PDF와 CSV도 저장소에 포함합니다.

검증은 고정 표본의 연간 수익률, 환율 분해와 직접 현금계산의 일치, 분기 연결과 연간 결과의 일치, 기업 시나리오의 부호·스트레스 조합을 확인합니다. 기존 시장 수집·기간 정렬·바스켓·노트 검증도 함께 실행합니다. 자동 검증 통과는 외부 데이터의 정확성이나 분석의 예측력을 보장하지 않습니다.

## 작성 기여

김승현은 프로젝트 주제와 금융권 활용 목적, 지원 범위와 확장 방향을 정했습니다. Codex는 자료 수집·정리, 개발, 계산 검증, 분석 문안 초안 및 보고서 제작을 보조했습니다. 독립 개발이나 실제 고객 자산 운용·기업 상담 실적으로 표시하지 않습니다.

제출자는 분석 문안과 계산을 직접 검토하고 자신의 해석으로 설명할 수 있어야 합니다. 이 저장소의 자동 검증 기록은 제출자의 직접 검토 완료를 의미하지 않습니다.
