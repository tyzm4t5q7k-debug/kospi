# KOSPI × NASDAQ Coupling Lab

김승현의 금융시장 분석 포트폴리오. 시장·환율·현금흐름을 분석하고 기업금융·개인 자산관리·증권 리서치·자산운용에서 확인할 질문으로 연결합니다. 프로젝트 방향은 김승현이 정했으며 자료 정리·개발·분석 초안·검증에는 Codex를 활용했습니다.

## 대표 분석과 제출 자료

- [웹 포트폴리오](https://kospi-swart.vercel.app)
- [제출용 분석 보고서 PDF](public/reports/kim-seunghyun-finance-portfolio.pdf) — 개요·대표 분석 3편·출처와 검증 범위, 총 5쪽
- [계산·검증 기준](docs/methodology.md) 및 [면접 설명 준비](docs/interview-guide.md)

| 사례 | 질문 | 고정 표본의 관측 결과 |
| --- | --- | --- |
| 시장 동조화 | 장기 동행이 개별 연도의 성과까지 설명하는가? | 2015~2024년 연간 상관계수 0.831, 2024년에는 두 시장의 수익률 방향이 다름 |
| 환율 효과 | 달러 수익률을 원화로 환산하면 무엇이 달라지는가? | 2024년 NASDAQ 달러 +28.64%, 원화 환산 +47.26%. 같은 해 3분기에는 달러 +2.57%, 원화 -2.02% |
| 기업 현금흐름 | 수출 기업에는 환율 상승이 항상 유리한가? | 공개한 가정에서 순수취 기업 +400만원, 순지급 기업 -1,600만원. 금리·결제 일정도 함께 확인 |

앞의 두 사례는 각각 연간·월별 빈도의 고정 표본입니다. 연간 자료는 2차 편집 자료, 환율 사례는 FRED를 통해 제공되는 Nasdaq·미 연준 자료를 사용합니다. 기업 사례는 가상 입력값입니다. 자세한 출처·한계는 각 사례와 보고서에 표시하며 최신 시장 API와 혼합하지 않습니다.

계산 모델은 `lib/case-studies.ts`, 관측치는 `lib/case-data.ts`에 있습니다. `npm test` 후 `node scripts/export-case-study.cjs`로 웹 모델과 동일한 결과를 내보내고 `python scripts/build-submission-pdf.py`로 PDF를 재생성합니다(reportlab 필요). 원자료 CSV도 `public/research/`에 포함합니다.

## 계산 기준

1. 원자료는 Yahoo Finance Chart API에서 2024년 이후 일별 관측치를 수집합니다. 거래소 현지 날짜의 당일 자료는 미완성 가능성이 있어 제외합니다.
2. 비교할 시계열의 날짜를 먼저 맞추고 공통 시작일 값을 100으로 환산합니다. 한국과 미국의 같은 날짜 종가는 같은 시각이 아닙니다.
3. 수익률 상관계수는 가격 수준이 아니라 연속 공통 관측일 사이의 단순 수익률에 Pearson 공식을 적용합니다. 휴장일 때문에 여러 날짜에 걸친 구간이 포함될 수 있습니다. 인과관계나 선행성을 추정하지 않습니다.
4. 원화 환산 나스닥 수익률은 `(1 + 달러 수익률) × (1 + 원/달러 환율 변화율) − 1`입니다. 같은 날짜 환율을 사용한 근사치이며 환헤지, 세금, 거래 비용은 포함하지 않습니다.
5. 최대 낙폭은 선택 기간의 공통 관측일에서 `(현재 값 / 이전까지의 최고 값 − 1)`의 최솟값입니다. 장중 하락과 공통 날짜에서 제외된 거래일의 하락은 반영하지 못할 수 있습니다.
6. 섹터는 모든 구성 종목의 공통 시작일에 동일 금액을 투자하고 보유하는 바스켓입니다. 이후 비중은 변동합니다. 기간 선택은 이미 구성된 바스켓의 부분 구간을 비교하며 비중을 다시 같게 맞추지 않습니다. 누락 종목을 조용히 제외하거나 다른 종목으로 대체하지 않습니다.
7. 종목별 시계열에는 수정종가를 우선 사용합니다. 수정종가 시계열이 제공되지 않으면 해당 종목 전체에 일반 종가를 사용하며 `closeOnlySymbols`로 반환합니다. 지수와 개별 종목의 배당 처리 범위는 다를 수 있습니다.
8. `^TNX`의 실제 금리 값(%) 차이에 100을 곱해 bp로 표시합니다. 금리 변화는 채권 투자 수익률이 아닙니다.

## 데이터 처리

한 번의 수집에서 동일 종목은 한 번만 요청합니다. 최대 8개 요청을 동시에 실행하며 각 요청은 6초 제한이 있습니다. 실행 인스턴스 내 성공 응답을 5분 재사용합니다. 갱신 실패 시 최대 24시간 이내의 이전 성공 응답에 `stale: true`를 붙이며, 인스턴스가 교체되면 이 임시 저장도 초기화됩니다. 정상 지수 데이터가 없고 이전 응답도 없으면 API는 503을 반환합니다. 사이트가 닫혀 있을 때 실행하는 예약 수집은 포함하지 않습니다.

## 확장된 분석 도구

- 공통 시장 분석을 기본값으로 기업금융·개인 자산관리·증권 리서치·자산운용 관점의 질문을 제공합니다.
- 자산배분·환율 시나리오는 최초 비중에 각 자산의 동일 기간 수익률을 적용하고 가격·환율·교차효과의 기여도를 구분합니다. 차입·외화결제 시나리오는 변동금리 비중과 계산 기간, 달러 순수취액을 반영합니다. 모든 초기값은 예시 가정입니다.
- 경제 이슈 노트에는 날짜, 출처, 사실, 해석, 추가 확인 사항을 기록합니다. 공개 사이트에 쓰기 권한이나 서버 저장소를 추가하지 않았으며, 노트는 페이지 내에서 편집하고 JSON 파일로 보관·불러옵니다. 저장하지 않은 편집 상태로 떠날 때 브라우저가 확인을 요청합니다. 다른 사용자의 기록에 접근하지 않습니다.
- 이슈 날짜를 이후 첫 공통 관측일(최대 7일 이내)에 연결해 차트에 표시합니다. 현재 비교 기간 밖의 노트는 표시하지 않습니다.
- PDF 저장은 현재 지수 차트·핵심 수치·분석 관점·최대 300자 해석·연결한 이슈 제목과 출처·선택 시나리오를 A4 한 장에 담습니다. 긴 원본 노트는 노트 파일로 보관합니다. PDF는 브라우저에서 생성됩니다.
- PDF 한글 글꼴은 Fontsource Nanum Gothic에서 파생한 Coupling Lab Report입니다. 원본 OFL 라이선스와 저작권 고지는 `public/fonts/OFL.txt`에 포함합니다. `python scripts/prepare-report-font.py`로 재생성할 수 있습니다(fontTools 필요). 글꼴은 PDF 저장 시에만 내려받습니다.
