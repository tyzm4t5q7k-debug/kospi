내 PC의 토스 데이터를 홈페이지에서 보기

현재 PC에 이미 설정한 분
1. 준비된 open-stock-lab.cmd를 실행합니다.
2. PC 화면의 '내 PC 연결'을 펼치고 '연결 코드 만들기'를 누릅니다.
3. https://kospi-swart.vercel.app/stocks 에서 '내 PC 연결'을 펼칩니다.
4. PC에서 만든 일회용 연결 코드를 입력합니다. 토스 클라이언트 시크릿을 입력하는 칸이 아닙니다.
5. 브라우저가 로컬 네트워크 접근 권한을 물으면 이 홈페이지에 허용합니다.
6. 같은 홈페이지에 '개인 연결 사용 중'과 '토스증권 연결'이 표시되는지 확인합니다.

다른 방문자가 자신의 PC에서 처음 설정하는 경우
각 방문자는 본인 토스 Open API 이용 자격, 키, 허용 IP 설정과 PC 조회 프로그램이 필요합니다. 다른 사람의 키를 사용하거나 전달하지 마세요.

1. Node.js 공식 사이트에서 Node.js 24 LTS를 설치합니다.
   https://nodejs.org/
2. 프로젝트 소스를 내려받아 압축 해제합니다.
   https://github.com/tyzm4t5q7k-debug/kospi/archive/refs/heads/main.zip
3. 프로젝트 폴더의 .env.example을 .env.local로 복사하고, 본인의 TOSS_CLIENT_ID와 TOSS_CLIENT_SECRET 값을 그 파일에만 입력합니다.
   이 파일은 Git이나 공개 사이트, 채팅에 올리지 마세요.
4. 토스증권 PC 웹의 설정 > Open API > 허용 IP 관리에서 이 PC가 사용하는 공인 IP를 등록합니다.
   공식 안내: https://developers.tossinvest.com/docs
5. Windows에서는 프로젝트 폴더의 start-local.cmd를 실행합니다. 처음에는 패키지 설치와 빌드 시간이 필요합니다.
   다른 운영체제: 프로젝트 폴더에서 npm ci, npm run build 실행 후
   npm run start -- --hostname 127.0.0.1 --port 3012
6. http://127.0.0.1:3012/stocks 에서 연결 코드를 만들고 위 절차로 홈페이지에 연결합니다.

사용 범위
- 추가 클라우드 서버 요금 없이, 연결 프로그램을 실행한 같은 PC에서 사용합니다. PC 전원과 인터넷 연결은 필요합니다.
- Chrome 등 로컬 네트워크 접근을 지원하는 브라우저가 필요합니다. 지원하지 않거나 권한이 차단된 경우 PC 화면을 직접 사용합니다. 브라우저 보안 기능을 끄지 마세요.
- 코드는 5분 동안 한 번 사용할 수 있습니다. 개인 연결은 최대 8시간이며 브라우저 탭에 저장됩니다.
- 프로그램을 재시작하거나 PC를 껐다 켜면 새 연결 코드가 필요합니다.
- 홈페이지에서 '개인 연결 해제'를 누르면 그 탭이 공개 시세로 돌아갑니다. PC 화면의 '모든 개인 연결 해제'는 발급된 모든 연결을 취소합니다.
- 토스 비밀키는 PC 밖으로 전송하지 않습니다. 홈페이지가 사용하는 연결 토큰은 시세·차트·수급 조회 전용입니다. 계좌 조회와 주문은 지원하지 않습니다.
- 토스 연결에 실패하면 화면에 출처와 오류를 표시합니다. Yahoo 시세가 나오면 토스 연결 성공으로 보지 마세요.
- 공유 PC에서는 사용 후 개인 연결을 해제하고 탭을 닫으세요.
